## 八参谋判决汇总

### 采信并排期实装

1. **租赁市场三件套**（参谋C + Worker 学术检索双确认）：净年化收益率、yield 归因（把收益拆成租驱动/价驱动两部分）、出租渗透率 lease_num/survive_num——行情站A/B（本框架采集的两家公开行情站点，开源版已移除对应适配器）中的行情站A 已有全套端点：info/good 响应本就含租赁字段，另有 chart?platform=2&key=lease_*，接入成本≈0
2. **事件驱动框架**（参谋B + 学术 FEM 论文修正）：事件分四类（供给机制/需求热度/规则变更/cosmetic，即外观类饰品）。单个饰品的事件用市场模型（以指数收益回归个品收益、取残差作异常收益）+ 行情站B 指数基准；全市场事件必须用双重差分（比较受事件组与未受事件组在事件前后的变化之差，以剔除共同冲击）。FEM 论文的教训：共同冲击会被 β 吸收，制造 AR（异常收益）≈0 的假象
3. **流动性陷阱评分 TrapScore**（参谋D + CSTrader 消融证据）：按品类内分位做组合；消融实验（去掉单个组件后重跑、以成绩差衡量其贡献）显示该因子贡献 12% 收益
4. **板块风险偏好温度计 L/U 比**（参谋H）：√(刀指数×手套指数)/步枪指数，类比股市的成长/价值比
5. **活跃度修正宽度**（参谋H）：宽度（样本中上涨标的占比一类的市场广度指标）只在活跃集上计算，活跃率另作独立变量
6. **磨损梯度斜率**（参谋A + Aalto 学位论文实证：float（饰品磨损浮点值）幂律弹性 R²=0.87）：用 Theil-Sen 回归（对离群点稳健的斜率估计）计算磨损—价格斜率，变陡=收藏盘（收藏需求主导的行情段）
7. **上架流磨损分布左移**（参谋A）：优质库存涌出=高位分发（持有人向高位接盘者分散出货）信号
8. **领先滞后 CCF 检验**（参谋G）：先用 CCF（互相关函数，检查一个序列领先/滞后另一序列时的相关结构）做检验，再决定是否构造领先动量——7 天持有期（hold）使跨平台跟随基本不可交易，但同平台定价与风控可用

### 采信方法论（指导回测纪律）

- **因子验证协议**（参谋E）：Rank IC（因子值排序与随后收益排序的截面相关）每周三截面；NW t 检验（Newey-West 稳健 t 检验）；Bonferroni 多重检验（按检验次数收紧显著性门槛以控制假阳性）；切分对齐断点：训练 2024H1-2025-06 / 验证 2025-07-12 / 测试 2026-02+。费后门槛 IC≥0.08 且 ICIR（IC 均值除以其标准差，衡量因子稳定性）≥0.5
- **摩擦感知**（CSTrader 消融 3.5 倍缩水证据 + 参谋E 换算）：三方月换（第三方平台的月度换手）IC*>0.13、Steam 侧不可行
- **零成交处理**（Frontiers 论文"完整记录筛选法"）：不插补，缺失即剔除
- **幸存者偏差动态截取**（红队二号）：幸存者偏差指只用今天仍在采集的标的回测、从而高估历史表现；对策是验证起点以当期实际覆盖为准

### 红队二号的批判（全部采纳为 V1 指标的使用警告）

- turnover 双向偏差（个体高估/总量低估，符号随退出率变化）
- supply_growth_7d 净额混淆（撤单潮会被误读为供给收缩）
- hoarding 测的是"幸存挂单密度"，不是惜售意图
- 日终 23:59 时间戳抹掉真实采样时点（冷门品噪声数倍）
- 采样强度按热度分层=对回归的选择偏差
- 10 指标最小独立集约 4-5 个（obi≈hoarding 的双侧版、supply_growth≈listing_rate 的积分、turnover/staleness/book_spread 同载活跃度、ret_7d⊂ret_30d、三指标共用 survive_num 分母而机械负相关）

### 明确不做（判决记录）

- 跨平台跟随套利：7 天 hold 使 2-4h 领先不可交易（参谋G 数学证明）
- Steam 市场任何轮换策略：15% 费率下 IC*>0.55 无人能达到（参谋E 换算）
- Reddit 情绪采集：CSTrader 的逆向情绪更优但数据不可得；官方新闻已被快速定价，且其事件 agent 消融后收益反降
- 事件 agent 的 LLM 化（同上证据）
